# 路流 FLOW

画道路、安排车流、调节红绿灯的中文交通规划沙盒。版本 0.1.0。

## 开始
双击 `index.html` 即可离线使用。或者执行：
```
node scripts/build.js
node scripts/serve.js
```
然后打开 http://127.0.0.1:4267 。无需安装第三方依赖。

## 玩法
无存档时从纯空白网格开始，有存档则恢复上次设计。地图上方的「空白地图」可随时重新开始，清空后支持撤销。「示例库」可预览并选择城市信号路网、双层高架跨线、菱形立交、四叶草立交、盘龙立交、单向环形分流六个案例。每个案例配好入口、出口与指定行驶路线，载入后可运行、继续编辑，也可撤销回原图。四叶草与盘龙为网格化简化示意，详见 [案例说明](doc/案例说明.md)。

1. 画路工具：拖动连接，或依次点击两个网格节点。
2. 入口 / 出口工具：在道路节点上放置入口和出口。
3. 每辆车从该入口所有可达出口里独立随机选一个，不固定目的地。选择入口时，虚线显示所有可选路线；不可达的出口会被排除。
4. 行驶方向工具：点击路段中间，切换单向/反向/双向。
5. 红绿灯工具：放在路口，调整绿灯秒数与初相。
6. 开始模拟，观察车辆、到达量、排队数与平均用时。
7. 立交桥工具（8）：点击十字交叉点，把一条道路架到另一条上方；再次点击可换桥上方向。桥上桥下只可直行，不会互相转入。选择桥可拆桥恢复平交，方向工具继续限制单行/双向。
8. 画路时，中途跨过已有道路默认不连接；可选新路在上、新路在下或连接路口。要接入交叉点，分段绘制，把交叉点作为一段的端点。
9. 行驶路线工具（9）：先点击入口，再按顺序逐段点击道路，最后点击出口。车会严格沿这条路线前进。入口设置可「添加另一条路线」，也可为同一出口画不同途经路线；点击列表单独预览，点右侧 × 仅删除这一条，支持撤销/重做。车辆在候选路线间随机分流；删除最后一条后该入口恢复自动避堵。

编辑会暂停并重置车辆和统计，保留路网。Ctrl+Z 撤销，Ctrl+Shift+Z 重做；1–9 切换工具。地图内方向键移动，Enter/空格操作。空白处空格开始/暂停，Escape 取消连线。

设计自动保存到当前浏览器/设备。JSON 导出可用于备份和迁移，导入会验证数据。隐私模式或存储受限时请使用导出。

各入口独立根据自己的道路空位发车，无全局 180 辆停发限制。入口前方排队时会等待腾位，侧栏显示等待原因；切换其他标签页会自动暂停，可点击开始模拟继续。

未指定行驶路线时，车辆先随机选择可达出口，再按剩余路程、车道排队和预计红灯等待比较时间。行驶途中也会在路口前重算尚未走过的部分，保持原出口，不掉头、不逆行、不跨层转弯；只有明显更快才改道，并有冷却以减少反复切换。运行提示显示实际自动改道次数。手画的指定路线始终严格执行，不会被自动避堵覆盖。

## 验证
`node --test`；`node scripts/build.js` 构建后启动服务，再执行 `node scripts/browser-check.js` 运行浏览器检查（需 playwright@1.62.1，可通过 PLAYWRIGHT_MODULE 指定已有模块）。真实浏览器交互结果见 `doc/第一版本测试报告.md`。

这是自由沙盒，不设预算或通关条件；车辆使用简化的排队与路口互斥模型，非工程交通预测。

## 游戏大厅
通过 game-hub v0.4.0 及以上版本的「立即检查」→「游戏目录」安装「路流 · 交通规划」。游戏 ID 为 `traffic-planner`，存储合同为 `traffic-planner-dynamic-v1`。原生导出使用大厅文件保存桥，普通浏览器使用 JSON 下载。浏览器不同 origin（包括 localhost、127.0.0.1 和 file）拥有独立存档，可用导出/导入迁移。发布状态见 [接入记录](doc/发布与大厅接入计划.md)。

## 项目结构与许可
`src/` 为路网、仿真、案例和界面；`tests/` 为 Node 回归；`scripts/` 为构建、七文件产物核验及浏览器验收；`dist/` 为固定运行资源。源码按 [MIT](LICENSE) 许可发布，不包含第三方运行库。Node 与 Playwright 仅用于开发和验证，静态应用不发布到 npm。
