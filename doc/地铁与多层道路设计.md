# 地铁与多层道路设计

日期：2026-10-27；状态：实施中。用户已确认线路逐站停靠、终点折返、六节编组及站台数除三向下取整的列车总量。

高度作为节点身份：地面沿用 x,y，其它层为 x,y@层号，范围地下八层到高架八层。同一平面位置可拥有独立节点和路段，原有地面道路与局部双层桥保持。普通线段等高，坡道在一个网格段内改变一层；较长坡道在绘制段中间升降。绘图、命中、车体和设施使用统一高度投影；按高度依次画完整路面、桥面和车辆，保证遮挡顺序。切层只改变编辑视图，不改图或重置模拟。

v1 存档扩展可选 mode/stations/trainCars 字段；地面路网不补无关字段，旧图往返保持。道路模式和地铁模式使用各自存档键，选择模式单独记忆。地铁站台同步为 sources/exits，但路网校验只在地铁模式允许这种重合。层间连接必须有合法坡道边，寻路不通过投影位置猜连接。

地铁使用单独仿真模块，接口与道路运行面板兼容。routes 数组保存手画线路，绘制期间经过站台不会提前结束，通过完成按钮定线；沿线全部站台组成停站序列。编组默认为六节，按车厢间距和车身长度计算整列占用。固定列车池大小为 floor(stations.length/3)，分配到合法往返线路，空间不足时在库等待，绝不无限发车。两条行驶方向采用各自轨道偏移，同向通过整列占用检查跟车，多线交叉按路口预约互斥，车尾驶离后释放。终点折返前确认对向轨道可用。

列车在站台停车两秒后发车；端点站台向线路内侧延展，保证整列留在线路上。线路不足以容纳六节编组时提示延长；运行中不剪短或重叠车厢。统计分别显示在线列车、固定总量、停站次数与平均站间用时，沿用开始/暂停/倍速/重置操作。列车按手画线往返，不参与道路随机出口及自动倒车逻辑。
