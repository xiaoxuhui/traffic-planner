# 路流阶段性总结

2026-10-21，版本 0.1.0，本地交付。

已交付：纯空白起步、自由道路绘制（中途跨线/端点接入、指定上下层）、单向/双向方向、逐段指定车辆路线、红绿灯、多入口出口、逐车随机出口、排队仿真、到达与耗时统计、撤销重做、自动保存及 JSON 迁移、上下遮挡的双层独立通行。

验证：63 项 Node 测试、42 项真实 Chromium 检查全部通过。静态构建 7 文件（含 MIT），支持直接打开 index.html 或本机服务，依赖仅用于开发时浏览器验收。已指定路线的车辆不擅自改道，线路失效会停发。

本机主页面为 http://127.0.0.1:4267/ ，独立测试页为 http://localhost:4267/ 。测试页与原页面的存档隔离，用户当前路网不用于测试操作。

已创建并推送公开仓库 xiaoxuhui/traffic-planner，正式发布 v0.1.0，加入大厅动态目录26；版本及资源身份见公开发布记录。

修复局部拥堵时固定 180 辆全局限制误停其他入口，以及下游空间不足造成路口占用互锁。实际路网连续模拟 600 秒的持续发车与到达回归通过；闭环队列可以在路口许可时协同预约前进。

自动车流在出发前按道路负载选路，连通的分流支路有实际流量；指定路线始终优先。新增六例可选案例库：城市、高架、菱形、四叶草、盘龙、单向环路；全有预设行驶路线，可继续编辑。盘龙为 6 入口、8 跨线、30 路线的网格化简化示意。可在手机预览选择，加载可撤销，重复加载同例重置模拟。
