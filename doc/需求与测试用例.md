# 路流 · 交通规划沙盒 — 需求与测试用例

版本：0.1.0；日期：2026-10-21；状态：实施中。

## 目标与范围
交付可本地离线打开的中文浏览器游戏。用户画道路、指定方向、放置信号灯、设置车辆来源与目的地，然后观察交通。首版采用自由沙盒，不设预算或胜负条件；真实交通法规和微观驾驶物理不在范围内。

## 规则
- 25 × 17 网格，水平/垂直道路；两点连线自动折成直角。点击两端或拖动均可修路。
- 每段道路可双向、正向或反向，方向工具依次切换；箭头说明方向。
- 入口和出口只能放在道路节点。每个入口可指定一个出口，或自动选可达出口；无路可达时不生成车辆并显示提示。
- 红绿灯控制该节点的东西/南北进入方向，周期含清空路口的全红时间；车辆在停止线排队。
- 同一车道保持间距，多入口争用交叉路口时串行通行。车辆到出口计为到达。
- 模拟可开始、暂停、倍速和重置；编辑路网时暂停并清空正在行驶的车辆及统计。
- 支持撤销/重做、示例、新建空图、手动保存和自动保存、JSON 导入导出。读取时验证数据，不执行导入内容。
- 桌面、手机可用；按钮具名，网格支持方向键移动焦点，Enter/空格放置或连线；快捷键不干扰表单。

## 验收
| 编号 | 用例 | 预期 |
|---|---|---|
| U01 | 拖动/点击两个网格点 | 连续直角道路，可形成交叉口 |
| U02 | 切换一段路方向 | 寻路只沿许可方向，逆向不通 |
| U03 | 放置信号灯、调整周期/初相 | 红灯停车，绿灯放行 |
| U04 | 设置多个入口/出口及目标 | 车辆从入口驶向指定出口 |
| U05 | 不可达入口、孤立出口、空图 | 明确提示，不生成无效车辆 |
| U06 | 运行、暂停、倍速、重置 | 时间及统计一致，暂停不前进 |
| U07 | 多辆车和交叉车流 | 跟车间距、交叉口互斥、能持续到达 |
| U08 | 删除道路/入口/灯 | 无悬空引用，支持撤销重做 |
| U09 | 保存、刷新、导出导入 | 设计保留，非法数据被拒绝 |
| U10 | 桌面与 390px 手机 | 控件可用、无横向页面溢出 |
| U11 | 键盘修路 | 焦点可见，方向键与 Enter 可完成连接 |
| U12 | 离线入口、构建 | 相对资源引用，源码与 dist 一致 |
