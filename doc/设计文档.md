# 路流 · 设计文档

版本 0.1.0；状态：实施中；策略：领域模型 → 仿真 → 界面 → 浏览器验证。

## 设计目标
1. 用户能看懂道路方向、车流入口和出口以及灯的状态。
2. 编辑即时可见，无存档默认空图，示例按需载入，手机也能完整操作。
3. 道路、寻路与车辆规则不依赖 DOM，可用 Node 原生测试验证。

## 分层
- `src/core.js`：UMD 纯模型。整数网格节点、邻接有向边、BFS、验证与序列化。
- `src/simulation.js`：固定步长仿真，队列、信号灯、交叉口占用锁、统计。
- `src/app.js`：状态协调、编辑历史、SVG 渲染、指针与键盘输入、持久化。
- `styles.css` / `index.html`：深色控制台 + 绿色规划地图，图标采用内联 SVG；无网络字体与外部运行依赖。

## 数据
`{version:1, roads:[{a:'x,y',b:'x,y',dir:'both'|'forward'|'reverse'}], sources:[{node,target}], exits:[node], signals:[{node,cycle,offset}], demand}`。
每条边只连接相邻网格点。规范化端点后保存方向。删除孤立节点时同时清理附属设施与目的地引用。导入严格验证数量、坐标、相邻关系、方向、引用与取值范围。

## 仿真
BFS 沿有向邻接图求最短路径。入口按 demand 设定尝试发车，受首段空间限制，不可达则不发车。0.7 为停止线；交叉口有独占锁，车辆离开路口一段距离后释放。同一有向边的车辆保持最小间距，驶入已满的下一段时不进入路口。信号灯东西/南北交替，各绿灯后有 1 秒全红。统计记录到达数、在途数、停车数、平均旅行时间；仿真是教学近似而非工程交通预测。

## 交互
工具：选择、画路、方向、信号灯、入口、出口、删除。SVG 使用透明点击节点与道路命中层，线路箭头持续可见。画路支持拖动或两次点击、Escape 取消。右侧检查器编辑入口目的地、道路方向、灯周期。历史最多 60 项。路网编辑自动暂停，避免旧路径引用。

## 失效处理
localStorage 失败时提示并保留内存状态；导入最多 1MB 且严格验证。空图与不可达入口给出引导。预览服务绑定 localhost，限制路径穿越。构建仅复制白名单源文件到 dist。

## 空白地图修正（2026-10-21）
移除场景装饰层及画布中央空态卡片。空态说明显示在地图上方标题副文案，画布仅保留网格。新建空图按钮位于地图工具栏，在窄屏也可见，并自动选择绘制道路工具。存储缺失或损坏均使用 `empty()`，保持有效存档恢复行为。

## 验证
`node --test` 验证领域行为与结构，`node scripts/build.js` 验证构建。真实浏览器检查绘路、方向、灯、来源目标、运行/暂停、保存恢复与移动布局，保存截图与测试报告。
